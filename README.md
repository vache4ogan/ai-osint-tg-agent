# 🤖 Автономный мультиагентный OSINT Telegram-бот (LangGraph + CRAG)

Автономная мультиагентная система, предназначенная для мониторинга IT-индустрии, агрегации технологического контента и автоматической генерации фактчекинговых публикаций для Telegram-каналов.

Проект построен на базе фреймворка **LangGraph** для оркестрации команды специализированных ИИ-агентов с использованием локальных LLM и паттерна **Corrective RAG (CRAG)** для полной ликвидации галлюцинаций. Особое внимание уделено production-практикам: отказоустойчивости (Retry-механизмы), семантическому поиску и автоматической оценке качества пайплайна.

---

## 📐 Архитектура системы и воркфлоу агентов

В проекте реализован продвинутый пайплайн на основе **Рефлексии (Reflection)**, **Адаптивного поиска (CRAG)** и **Семантического чанкинга**:

1. **Scout (Парсер):** Мониторит RSS-ленты и парсит сырой HTML с технологических платформ (например, Хабр). Кэширует обработанные URL во избежание дубликатов.
2. **Semantic Chunker:** Перед сохранением в векторную базу тексты дробятся с помощью `SemanticChunker` — алгоритма, который использует эмбеддинги для объединения предложений по смыслу (косинусное расстояние), сохраняя контекст целым. К чанкам прикрепляются расширенные метаданные (источник, дата).
3. **Retriever Node:** Выполняет семантический поиск по локальной векторной базе данных (ChromaDB) с использованием мультиязычных эмбеддингов.
4. **Router (CRAG):** Оценивает качество извлеченного контекста. Если информации недостаточно для раскрытия темы, динамически активирует инструмент **Web Search** (API DuckDuckGo) для добора актуальных фактов из интернета.
5. **Writer Node:** Генерирует черновик публикации, опираясь *строго* на собранные факты, соблюдая заданную SMM-структуру и tone of voice.
6. **Critic Node (Валидация через Pydantic + Retry):** Выступает в роли безжалостного главного редактора. 
   - Проверяет текст на галлюцинации с помощью схемы `with_structured_output` (Pydantic). 
   - Имеет встроенную **Retry-логику**: если локальная модель отдает некорректный JSON, граф перехватывает ошибку и замыкается сам на себя, передавая текст ошибки Pydantic обратно модели с требованием исправить структуру.
   - Возвращает структурированный фидбек Писателю (максимум 3 итерации переписывания).
7. **Human-in-the-Loop:** После прохождения Критика бот отправляет финальный вариант в Telegram-панель администратора на модерацию (Опубликовать / Перегенерировать / Отклонить).

## 🛠️ Технологический стек

* **Оркестрация агентов:** LangGraph, LangChain, Ollama (`llama3` / `qwen2.5`)
* **Оценка качества (Evaluation):** Ragas, Datasets, Pandas
* **Векторная база и эмбеддинги:** ChromaDB, HuggingFace Embeddings (`paraphrase-multilingual-MiniLM-L12-v2`)
* **Данные и инфраструктура:** SQLite (кэширование запросов), BeautifulSoup4, Feedparser
* **Интерфейс и асинхронность:** Aiogram 3.x

│   └── graph.py                  # Сборка, компиляция и оркестрация графа LangGraph
│
├── src/                          # Вспомогательные сервисы ядра проекта
│   ├── __init__.py               
│   ├── config.py                 # Загрузка переменных окружения и токенов
│   ├── parser.py                 # Логика веб-скрейпинга и парсинга
│   ├── chanking.py               # Продвинутый Semantic Chunking и обогащение метаданными
│   ├── llm_core.py               # Инициализация локальной LLM (Ollama)
│   ├── database.py               # Модуль работы с БД
│   └── tg_bot.py                 # Telegram-бот для интерактивной модерации (HITL)
│
├── evaluate_rag.py               # Скрипт оценки качества RAG-пайплайна (Faithfulness и Answer Relevance)
├── chroma_db/                    # Локальная векторная база данных Chroma (создается при запуске)

## 🚀 Быстрый запуск

### 1. Настройка окружения

```bash
git clone https://github.com/ваш-никнейм/langgraph-rag-content-bot.git
cd langgraph-rag-content-bot

# Создание и активация виртуального окружения
python3.10 -m venv venv
source venv/bin/activate

# Установка основных зависимостей
pip install -r requirements.txt

# ДОПОЛНИТЕЛЬНО: установка модулей для Semantic Chunking и Ragas
pip install langchain-experimental ragas datasets pandas
```

### 2. Запуск локальной LLM через Ollama

Убедитесь, что Ollama установлена и запущена на вашем компьютере:
```bash
ollama run llama3:latest
```

### 3. Оценка качества пайплайна (Evaluation)

Вы можете протестировать способность пайплайна не допускать галлюцинаций с помощью локального запуска бенчмарков Ragas:
```bash
python evaluate_rag.py
```

### 4. Настройка конфигурации и запуск бота

Создайте файл `src/config.py` в директории проекта:
```python
# src/config.py
token = "ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА"
```

Запустите Telegram-бот как модуль пакета из корневой директории:
```bash
python -m src.tg_bot
```
